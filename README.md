# sonceibe-studio

> Create music videos from your songs, lyrics and creativity.

SonCeibe Studio es una aplicación de escritorio orientada a músicos y creadores que permite crear lyric videos profesionales de forma sencilla.

## Estado del proyecto

🚧 En desarrollo

Actualmente incluye:

- Reproducción real de MP3
- Editor de letras
- Timeline
- Waveform
- Vista previa en tiempo real
- Sincronización manual y Tap Sync

## Objetivos

- Sistema de proyectos (.scs)
- Plantillas
- Exportación MP4
- Aplicación de escritorio para Windows
- Automatización mediante IA

## Tecnologías

- Next.js
- React
- TypeScript
- Tailwind CSS

## Filosofía

- Nunca perder el trabajo del usuario.
- Proyectos autocontenidos.
- Compatibilidad entre versiones.
- Código modular.
- Desarrollo incremental.
